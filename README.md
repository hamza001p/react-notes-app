# React Notes App 📝

A simple and responsive Notes App built with React. This project allows users to manage their notes and practice core React concepts.

## ✨ Features

- Create new notes
- View saved notes
- Edit existing notes
- Delete notes
- Responsive user interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hamza001p/react-notes-app.git
```

### 2. Navigate to the project folder

```bash
cd react-notes-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the application.

## 📚 Learning Objectives

- Understanding React components
- Managing state with React hooks
- Passing data using props
- Implementing CRUD operations
- Building reusable UI components
